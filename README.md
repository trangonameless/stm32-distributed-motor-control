# stm32-distributed-motor-control
Distributed embedded motor control system based on STM32, CAN and Raspberry Pi.

## Final Architecture

- STM32L476 Motor ECU
- STM32F103 Control ECU
- CAN Bus
- Raspberry Pi Supervisor
- MQTT
- Grafana
- PID Controller
- DC Motor with Encoder
